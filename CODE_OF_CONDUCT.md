# Code of conduct

This gallery is for sharing looks. Keep it friendly.

- Be kind in issues, pull requests and reviews.
- Share only looks you made, and credit the look yours started from.
- No private data in screenshots: notes, mail, chats, names, faces.
- No hateful, sexual or violent images, names or descriptions.

I remove what breaks these rules, and may block an account that keeps
doing it. To flag something, use
[**Report a look**](../../issues/new?template=report-look.yml).
